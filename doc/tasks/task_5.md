# 👁️ Задача 5: Разработка представлений (Views)

## Описание
Создать класс-базированные представления (CBV) для обработки запросов блога в соответствии со спецификацией README.md. Все представления реализуются в файле `blog/views.py`.

## Требования

### Список представлений
1. **PostListView** - список всех постов:
   - Пагинация (по 10 постов на страницу)
   - Контекст: список постов, пагинатор
   - Шаблон: `list.html`

2. **CategoryListView** - список всех категорий:
   - Контекст: список категорий
   - Шаблон: `categories.html`

3. **CategoryDetailView** - посты конкретной категории:
   - Пагинация (по 10 постов)
   - Контекст: объект категории, список постов категории
   - Шаблон: `list.html` (с фильтром по категории)

4. **TagListView** - список всех тегов:
   - Контекст: список тегов
   - Шаблон: `tags.html`

5. **TagDetailView** - посты с конкретным тегом:
   - Пагинация (по 10 постов)
   - Контекст: объект тега, список постов с тегом
   - Шаблон: `list.html` (с фильтром по тегу)

6. **PostDetailView** - детали поста:
   - Увеличение счетчика просмотров при каждом открытии
   - Контекст: объект поста, связанные посты
   - Шаблон: `detail.html`

### Особенности реализации
- Все представления наследуются от Django CBV (ListView, DetailView)
- Для пагинации использовать `Paginator` с параметром `paginate_by = 10`
- Для PostDetailView переопределить метод `get()` для увеличения счетчика просмотров
- Использовать `get_queryset()` для фильтрации по категориям/тегам
- Возвращать 404 при отсутствии объекта

## Проверка
- Все URL-пути корректно обрабатываются
- Пагинация работает корректно
- Контекст содержит ожидаемые данные
- Счетчик просмотров увеличивается при каждом открытии поста
- Ошибка 404 возвращается для несуществующих объектов
