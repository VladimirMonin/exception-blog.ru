# 🚀 Задача 1: Создание приложения blog

## Описание

Создать основное приложение Django для функционала блога. Это первая задача, которая должна быть выполнена перед реализацией моделей и представлений.

## Требования

1. Создать приложение командой:

   ```bash
   python manage.py startapp blog
   ```

2. Зарегистрировать приложение в `settings.py`:

   ```python
   INSTALLED_APPS = [
       # ...
       'blog.apps.BlogConfig',
   ]
   ```

3. Создать базовую структуру приложения:
   - `models.py` - для моделей данных
   - `admin.py` - для регистрации моделей в админке
   - `views.py` - для классовых представлений
   - `urls.py` - для маршрутов приложения

## Проверка

- Приложение отображается в списке INSTALLED_APPS
- Нет ошибок при запуске сервера (`python manage.py runserver`)

> Примечание: Шаблоны будут храниться в корневой директории `templates/` проекта, как указано в README.md
