# 🧪 Задача 7: Тестирование и наполнение данными

## Описание
Реализовать тесты для моделей, представлений и URL, а также создать механизм наполнения базы тестовыми данными.

## Требования

### Тестирование
1. **Модели**:
   - Проверка создания объектов Category, Tag, Post
   - Проверка автоматического заполнения slug
   - Проверка преобразования markdown_content в html_content
   - Проверка увеличения счетчика просмотров

2. **Представления**:
   - Проверка статус-кодов для всех представлений
   - Проверка контекста (правильные объекты в контексте)
   - Проверка пагинации
   - Проверка 404 ошибок для несуществующих объектов

3. **URL**:
   - Проверка разрешения URL в правильные представления
   - Проверка пространства имен `blog`
   - Проверка передачи параметров slug

### Наполнение данными
1. Создать фикстуры для моделей:
   - 5 категорий
   - 10 тегов
   - 20 постов (связи с категориями и тегами)
2. Реализовать кастомную команду `fill_db`:
   - Очистка базы перед заполнением
   - Создание тестовых данных
   - Вывод информации о процессе

### Инструменты
- Использовать `pytest` и `pytest-django` для тестирования
- Использовать `factory_boy` для создания тестовых данных
- Для фикстур использовать Django `dumpdata`/`loaddata`

## Проверка
- Все тесты проходят успешно
- Команда `fill_db` корректно создает тестовые данные
- Админ-панель отображает созданные данные
- Все страницы работают с тестовыми данными
