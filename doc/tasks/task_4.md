# 🖌️ Задача 4: Разработка шаблонов страниц

## Описание
Создать HTML-шаблоны для блога в соответствии со спецификацией README.md. Все шаблоны размещаются в корневой директории `templates/`.

## Требования

### Список шаблонов
1. `base.html` - базовый каркас:
   - Подключение Bootstrap 5 и Bootstrap Icons
   - Блоки: `title`, `meta_description`, `meta_keywords`, `og_tags`, `extra_css`, `content`, `extra_js`, `footer`
   - Инклюд `_menu.html`
   - Рекомендуемые OG-теги (как в README.md)

2. `_menu.html` - навигационное меню

3. `_post_card.html` - карточка поста:
   - Отображение обложки, заголовка, описания
   - Ссылка на детальную страницу

4. `list.html` - список постов:
   - Использование `_post_card.html` для каждого поста
   - Пагинация

5. `detail.html` - детальная страница поста:
   - Отображение `html_content`
   - Инклюд `_comments_block.html`

6. `_comment.html` - элемент комментария

7. `_comments_block.html` - блок комментариев и форма добавления

### Особенности
- Все шаблоны используют наследование от `base.html`
- Для постов используются компоненты `_post_card.html`
- Для комментариев используются компоненты `_comment.html` и `_comments_block.html`

## Проверка
- Корректное наследование и работа блоков
- Отображение контента соответствует макету
- Все компоненты работают корректно
