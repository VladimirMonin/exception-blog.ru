# 📝 Правила работы с задачами

## Структура задач
1. Каждая задача оформляется в отдельном файле `task_<номер>.md`
2. Все задачи хранятся в директории `doc/tasks/`
3. Главный файл `tasks.md` содержит таблицу статусов

## Формат задачи
```markdown
# [Эмодзи] Задача X: Краткое название

## Описание
1-2 предложения о сути задачи

## Требования
- Конкретные пункты, что нужно сделать
- Без излишней детализации кода

## Проверка
- Критерии успешного выполнения
- Что должно работать после реализации
```

## Рабочий процесс
1. При взятии задачи в работу:
   - Изменить статус на ⏳ в `tasks.md`
2. При завершении задачи:
   - Изменить статус на ✅ в `tasks.md`
   - Сделать коммит с названием задачи
3. При возникновении проблем:
   - Изменить статус на ❌ в `tasks.md`
   - Описать проблему в комментариях к задаче

## Статусы задач
- ⏳ - В работе
- ✅ - Выполнено
- ❌ - Не начато/Проблемы

## Рекомендации
- Дробить большие задачи на подзадачи
- Одна задача = один логический блок функционала
- Проверять выполнение всех требований перед сменой статуса на ✅
